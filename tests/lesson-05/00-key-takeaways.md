# **CÁC KIẾN THỨC BÀI 5**
## --- JAVASCRIPT FUNCTIONS ADVANCE --- ##

## 1/ Function expression
- Function expression là 1 biếu thức hàm, gán biến ngay từ đầu chứ không gán sau function()
- Cách gọi để trả kết quả của cả 2 tương tự nhau

## 2/ Lambda function
- Cách viết ngắn gọn hơn của function()
- Sử dụng dấu => thay cho function()
- Khi không có tham số thì phải có dấu ngoặc tròn rỗng
- Có 1 tham số thì có thể bỏ trống (hoặc cũng có thể giữ dấu ngoặc)

## 3/ Anonymous function
- Hàm ẩn danh, không thể đứng 1 mình
- Được dùng khi function chỉ sử dụng 1 lần hoặc làm callback

## --- DOM ---
## 1/ Khái niệm
- Bao gồm: header, ads, body, các khối text, các hình ảnh, liên kết, ... trong 1 website
- Cách nhìn nhận thẻ mở, thuộc tính, giá trị, thẻ đóng, ...
- Các thẻ cấu trúc cơ bản: <"html">, <"head">, <"body">, <"div">, ...
- Các thẻ nội dung: <"h1">, <"p">, <"a">, <"img">, ...

## 2/ Selector
- Tìm và tương tác tự động với các phần tử trên web
- Có 3 loại thường dùng:
    + XPath
    + CSS Selector
    + Playwright Selector

## 3/ Playwright basic syntax
- Các tương tác cơ bản như:
    + Navigation

    + Fill
    + Upload file
    + ...
